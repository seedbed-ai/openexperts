**Prerequisites and boundaries:** Applying the sales workflow to a real deal may require actual customer-provided deal context and separately authorized CRM access; the `expert.yaml` manifest's declared tools do **not** provide it. Sources are illustrative fixture content, not verified advice for particular commercial decisions.

**Remote navigation:** Read this index first, follow one selected document anchor using a repository reader with reliable section support. If section access is unavailable or clips necessary context, read that **single short document** instead; do not fetch the whole fixture. Keep repository revision and exact path/heading in the answer.

**Escalation:** If an index anchor is stale, the heading is missing, or a snippet is incomplete, search the target document's current headings and report the difference; if the evidence cannot be recovered, qualify the specific claim rather than inventing it.
