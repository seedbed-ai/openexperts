# Read-path exercise — original fictional B2B example

This is a reproducible navigation script, **not** evidence that any assistant has performed the steps.

For an unidentified budget approver: read `CATALOG.md`, then `examples/b2b-decision/INDEX.md`, then `examples/b2b-decision/APPROVAL.md#approval-evidence`, and finally `examples/b2b-decision/NEXT-ACTION.md#procedure`. Report unknown authority and the next evidence question.

For a delayed decision: use that same index, then `examples/b2b-decision/DELAY.md#decision-timing` and the next-action procedure. Distinguish a proposed funding-review follow-up from an approved purchasing date.

Report exact source revision and every document actually read. A broken link, unavailable section reader or unavailable repository must be disclosed. No external write or customer-state mutation is part of this exercise.
