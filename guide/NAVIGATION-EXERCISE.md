# Navigation exercise — sales fixture (review fixture only)

This exercise uses already-public OpenExperts fixture documents, not private Seedbed expertise. It specifies a reproducible read path for any ordinary AI host with a permitted GitHub/document reader. **This is a test script, not an observed model execution.**

### Question 1: What should a salesperson check if the buyer's budget approver is not known?

1. Read only `CATALOG.md`, choose B2B sales qualification.
2. Read `experts/radiant-sales-expert-fixture/knowledge/INDEX.md`, choose “Buying approval and decision authority.”
3. Read `experts/radiant-sales-expert-fixture/knowledge/meddpicc.md#criteria` (or that small complete document if reliable anchor reading is unavailable).
4. Answer based on the **Economic Buyer** criterion; report exact section/path and observed revision, and distinguish specific customer facts not supplied.

### Follow-up: What if the buyer keeps delaying?

5. Return to the **same topic index**, choose “Delay or no decision.”
6. Read only `knowledge/competitive-battle-cards.md#competitor-c--status-quo-do-nothing` (or the one short source document).
7. The fixture recommends estimating the buyer's cost of delay from their own metrics. Obtain missing buyer metrics or qualify the recommendation. Do not fabricate actual deal facts or tool access.

### Negative conditions

- **Index stale:** If the index anchor/target does not match the current document, report that it is stale and inspect current headings instead of treating the index summary as evidence.
- **Selected section missing:** Do not pretend the source supports the claim. Navigate related links or qualify the answer.
- **Partial reader:** If only a search snippet returns, label it a snippet. Request a narrowly scoped follow-up read or use the full *selected small document*, not the entire library.
- **No repository read tool:** Ask for the specific index/section text, clearly mark user-supplied evidence, and continue useful general assistance.
- **Wrong source/version:** Do not silently combine index revision A with leaf revision B; disclose and reconcile the mismatch.

### Expected evidence ledger

Report catalog/index/leaf paths actually read, source repository, observed revision (or “unknown”), specific consulted heading, and source status. Count fetched document bodies/sections, **not total corpus size**. No CI or cross-provider acceptance PASS is implied merely by committing this exercise.
